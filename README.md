# RCM Analytics

Enterprise Revenue Cycle Management (RCM) Analytics platform built with TanStack Start, React 19, Tailwind CSS, and TypeScript.

## Development

Requires Node.js / Bun / npm.

```sh
npm i
npm run dev
```

## Tech Stack

- TanStack Start & Router
- React 19
- Tailwind CSS v4
- Recharts & Lucide Icons
- TypeScript
